# Student Performance Analysis

This project analyzes a dataset of student performance to understand the impact of various demographic and behavioral factors on academic grades.

## Features

- **Performance Overview**: Visualizing average marks in Math, Science, and English, and the overall grade distribution.
- **Demographic Analysis**: Examining the effect of gender on final grades.
- **Behavioral Insights**:
  - **Study Hours**: Correlating daily study time with final grades.
  - **Parental Education**: Analyzing how parents' education levels relate to student performance.
  - **Attendance**: Investigating the relationship between class attendance and final grades.

## Observations

- **Study Habits**: There is a positive correlation between the number of hours studied per day and the final grade achieved.
- **Parental Influence**: Students whose parents have higher education levels tend to have slightly better performance distributions.
- **Attendance Matters**: Higher attendance percentages are strongly linked to better final grades, emphasizing the importance of classroom engagement.

## Technologies Used

- **Python**
- **Pandas**: For data analysis and grouping.
- **Matplotlib**: For creating bar charts and line graphs.

## Files

- `studentPerformance.ipynb`: Analysis notebook.
- `studentPerformance.csv`: Dataset containing student information and grades.
