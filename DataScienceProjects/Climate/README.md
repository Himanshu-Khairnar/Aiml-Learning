# Climate Data Analysis

This project analyzes historical temperature data for Seattle to identify trends and patterns, specifically focusing on temperature changes over the years.

## Features

- **Data Cleaning**: Preprocessing of `city_temperature.csv` to filter data for Seattle.
- **Heatmap Analysis**: Visualizing average monthly temperatures over multiple years using heatmaps.
- **Global Warming Trends**: Highlighting temperature deviations to observe global warming patterns.

## Observations

- **Seasonal Consistency**: The heatmaps clearly show consistent seasonal patterns in Seattle, with clear distinctions between warmer and colder months.
- **Temperature Anomalies**: By subtracting the mean temperature, the analysis highlights subtle shifts in weather patterns, which may be indicative of broader climatic changes or warming trends in recent years.

## Technologies Used

- **Python**
- **Pandas**: For data manipulation and analysis.
- **Matplotlib**: For generating heatmaps and plots.

## Files

- `Climate.ipynb`: The Jupyter Notebook containing the analysis code.
- `city_temperature.csv`: The dataset used for the analysis.
